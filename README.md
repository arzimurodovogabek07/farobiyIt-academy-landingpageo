# Farobiy IT Academy — Landing Page 🚀

Ushbu loyiha **Farobiy IT Academy** o'quv markazi uchun tayyorlangan zamonaviy va moslashuvchan (responsive) **Landing Page** veb-sahifasi hisoblanadi. Loyiha Figma dizayn maketi asosida piksellab (Pixel Perfect) yig'ilgan.

---

## 🌐 Jonli Havola (Live Demo)
👉 **[Saytni jonli ko'rish](https://arzimurodovogabek07.github.io/farobiyIt-academy-landingpageo/)**

---

## 🛠 Ishlatilgan Texnologiyalar
* **HTML5** — Semantik va toza struktura
* **CSS3** — Flexbox, Grid va zamonaviy stillar
* **Responsive Design** — Mobil, planshet va kompyuter ekranlariga moslashuvchanlik
* **Figma** — Dizayn maketini sifatli verstka qilish

---

## 📌 Asosiy Bo'limlar
- **Header & Navbar** — Navigatsiya menyusi va moslashuvchan menyu
- **Hero Section** — Asosiy sarlavha va kurslarni tanlashga chaqiruv
- **Kurslar (Courses)** — O'quv markazida mavjud barcha yo'nalishlar kartochkalari
- **Ustozlarimiz (Mentors)** — O'qituvchilar va yo'nalishlari
- **Biz haqimizda (About Us)** — Markazning maqsad va qadriyatlari
- **FAQ (Savol-javoblar)** — Ko'p beriladigan savollar bloki
- **Ariza qoldirish (Contact Form)** — Kursga yozilish formasi
- **Footer** — Manzil, aloqa vositalari va ijtimoiy tarmoqlar
